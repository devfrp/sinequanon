Courbes Feuille de route GitHub

Le traceur de courbes, réécrit en Rust.

Fonctions, courbes paramétrées et polaires sur papier millimétré, exportées en SVG.

Télécharger la v0.2.0 Voir le code

Quatre manières de tracer.

y = f(x), avec la multiplication implicite : 2x et 3sin(x) s’écrivent comme sur la calculatrice.

x = X(t) et y = Y(t), séparés par un point-virgule, sur le domaine de t que vous fixez.

r = f(θ), en tapant theta ou θ. La rose à trois pétales tient sur une demi-période.

Une échelle logarithmique sur un axe ou sur les deux : log(x) devient une droite.
